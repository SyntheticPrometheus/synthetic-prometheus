Why tiling layouts survive

A tiling window manager arranges windows so that no pixel is wasted. The argument for it is not aesthetic, it is about keyboard-driven control and predictable geometry.

Three costs

First, the learning curve is real. Second, applications that expect to be resized freely misbehave. Third, multi-monitor setups need a policy that most implementations do not state.
